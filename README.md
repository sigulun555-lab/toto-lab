# toto-lab

ChatGPT / Claude の toto 予測を、同じ試合・締切・採点基準で比較する共有基盤。

## 現在の段階
- 公式クラブ名称の基準リストを `data/teams.json` に保存。
- 予測・結果のJSON形式と検証/採点処理を順次追加する。
- API予測生成・試合結果取得は、データ源とSecretsの設定が完了するまで有効化しない。
- モデルの補正（例：シュリンケージ）は比較結果が蓄積するまで本番採用しない。

## 正式名称の根拠
Jリーグ公式「2026特別シーズン、2026/27シーズン クラブ編成」
https://www.jleague.jp/news/article/32852/

`canonical` は公式資料の表記。短い別名は既存データとの照合を助ける候補であり、文脈なしに一意とは限らない短縮名（例:「栃木」「横浜」）は試合データとリーグも使って確認すること。

## 予測レコードの原則
- 確率キー: `1`=ホーム勝ち、`0`=引き分け、`2`=アウェイ勝ち。
- 確率は0〜1、合計は約1。
- `predictionConfirmedAt` と `deadlineAt` はUTC ISO8601（Z終端）。
- 締切後予測は採点しない。
- 予測ログは追記専用。修正時は新しいIDを作り `revisionOf` を設定。
- 結果は予測ログと分離する。
- APIキーはコードに入れず GitHub Actions Secrets に保存する。

## Secrets（後で設定）
- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
