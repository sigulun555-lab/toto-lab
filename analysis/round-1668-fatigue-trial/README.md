# 第1668回 疲労補正トライアル — 休養日数の再現可能な集計（2026-10-30訂正版）

GPT側から指摘された、最初に口頭で報告した集計（Issue #23コメント）の件数不整合を
修正し、再現可能な中間データを添付する。

## データソース

`sigulun555-lab/gpt` リポジトリ `data/history.json`（community_jleague_csv由来、
J1/J2/J3、2026-08-07〜10-25、380試合、xGなし）。

## 休養日数の算出方法

各チームについて、全大会（J1/J2/J3を跨いで同一チームとして扱う）の試合を日付順に
並べ、前試合からの暦日差を「休養日数」とした。初戦（直前の試合が無い）は対象外。
結果、700件の「チーム×試合」レコードが得られる（`rest_days_table.csv`）。
列：`team, date, rest, comp, gf, ga, gd, pts`（`gf`=得点, `ga`=失点, `gd`=得失点差,
`pts`=その試合の勝点）。同一試合はホーム側・アウェイ側で2レコードになる（独立では
ないため、後述の通り団体内比較でも確認している）。

19〜22日の28件は、データ収集期間の開始直後（シーズン序盤の初戦前後）に集中して
おり、通常の「長い休養」とは性質が異なる左側打ち切り的なノイズと考えられる。
最初の報告では、この28件を「long(6+)」に含めてしまっていたため、`n=527`という
誤解を招く数字になっていた。今回は以下のように分類し直した。

- `short(<=3)`：39件
- `mid(4-5)`：134件
- `long_core(6-8)`：499件（6〜8日のみ。通常の週1試合＋ミッドウィーク程度の範囲）
- `long_outlier(9+)`：28件（比較には使わない）

## 比較1：単純プール比較（short vs long_core）

| 群 | n | 平均得失点差 | 平均勝点 |
|---|---|---|---|
| short(<=3) | 39 | +0.026 | 1.205 |
| long_core(6-8) | 499 | -0.004 | 1.371 |

差（得失点差）= +0.030、SE = 0.301、**95%信頼区間 = (-0.560, +0.620)**。
ゼロを大きく挟んでおり、有意な差ではない。

## 比較2：チーム内ペア比較（short vs long_core、同一チームのみ）

同一チームがshort(<=3)とlong_core(6-8)の両方を経験している33チームについて、
各チーム内でのshort平均とlong平均の差を取り、33チーム分の差の平均を検定した
（チーム力・対戦相手の強さの違いを部分的に打ち消すための方法。ホーム/アウェイの
記録が同一チームに混在する点の非独立性にもある程度対応できる）。

- n_teams = 33、平均差 = +0.034、SD = 1.772、SE = 0.309、t = 0.11
- **95%信頼区間 = (-0.571, +0.638)**

単純プール比較・チーム内ペア比較のいずれも、方向さえ一貫せず（わずかにプラス）、
ゼロを大きく挟む信頼区間となった。

## 結論

- 利用可能な380試合・2.5か月分のデータでは、休養日数3日以下による成績低下を
  有意に検出できなかった（効果が「ない」と断定するのではなく、**この小標本・
  短期間データでは効果量を十分な精度で推定できなかった**、という結論）。
- xGデータが無く得点/失点のみで見ているため、シュート品質等の変化を捉えられて
  いない可能性がある。
- 複数シーズンのデータが蓄積されたら、同じ方法（`rest_days_table.csv`と同じ列構成）
  で再集計し、サンプルサイズの増加で信頼区間が狭まるか確認する。
