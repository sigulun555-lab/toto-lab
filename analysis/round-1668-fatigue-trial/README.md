# 第1668回 疲労補正トライアル — 休養日数の再現可能な集計（2026-10-30 再訂正版）

GPTからの2度の独立検証で2つの問題を指摘され、両方を修正した。

## 訂正履歴

1. **件数の不整合（1回目の指摘）**：最初の報告で「中6日以上n=527」としていたのは
   6〜8日（499件）と9日以上の外れ値（28件）を区別せず合算したものだった。
   → `long_core(6-8)` として6〜8日のみに限定する形で修正済み。
2. **「中N日」の定義そのものが1日ずれていた（2回目の指摘、より本質的）**：
   前試合日から対象試合日までの**暦日差**（例：10/21→10/25なら4日）を、サッカーで
   言う「中N日」としてそのまま使っていたが、正しくは
   `rest_days_between_matches = calendar_day_gap - 1` （例の場合は中3日）。
   このズレにより、**今回問題にしている第1666回totoGOAL3指定6チームの実際の
   ケース（中3日）が、旧集計のshort(<=3)バケットから漏れていた**（旧バケットは
   実質「中2日以下」を集計していた）。

## データソースと算出方法

`sigulun555-lab/gpt` リポジトリ `data/history.json`（community_jleague_csv由来、
J1/J2/J3、2026-08-07〜10-25、380試合、xGなし）。

各チームについて、全大会（J1/J2/J3を跨いで同一チームとして）の試合を日付順に
並べ、前試合からの暦日差（`calendar_day_gap`）と、そこから導く休養日数
（`rest_days_between_matches = calendar_day_gap - 1`）を算出。700件の
「チーム×試合」レコードを `rest_days_table.csv` に保存（列：
`team, date, calendar_day_gap, rest_days_between_matches, comp, gf, ga, gd, pts`）。

再現方法：
```
python3 analysis/round-1668-fatigue-trial/compute_rest_days.py \
  <gpt-repoのdata/history.jsonのパス> \
  analysis/round-1668-fatigue-trial/rest_days_table.csv
node --test analysis/round-1668-fatigue-trial/compute_rest_days.test.js
```

### 第1666回→第1668回の休養日数：集計データの適用範囲外であることの明記

第1666回totoGOAL3（10/28開催）→第1668回（10/31開催）は暦日差3日・
**中2日**（`rest_days_between_matches=2`）にあたる。これは**日付の引き算による
分類であり、`rest_days_table.csv`（データソースは`history.json`、2026-08-07〜
**10-25**まで）に基づく実測データではない**。10/28開催・10/31開催はいずれも
データ取得期間（〜10/25）より後であり、この6チームの実際の第1666回→第1668回の
試合は`rest_days_table.csv`の700件にも、`short(<=3)`バケットのn=165にも
**含まれていない**。

したがって、「この6チームのケースがshort(<=3)バケットに属する」という記述は、
あくまで中N日の定義上の分類（暦日差3日なら中2日、だからshort(<=3)の範囲内、
という算術的な当てはめ）であって、実測によってそのバケットの集計値（n=165や
平均値）にこのケースが含まれている、という意味ではない。以下の比較1・比較2の
集計値（n=165/387など）は、データ取得期間内（〜10/25）に実際に発生した700件の
チーム×試合レコードのみから算出した探索的な参考値であり、第1666回→第1668回の
ケースそのものを直接観測した結果ではない。
参考として、同じ6チームが直近（データ取得期間内）に経験した「中3日」の実例
（10/21開催→10/25開催、暦日差4・中3日）は`rest_days_table.csv`の該当行で
確認できる（これは実測データだが、第1666回→第1668回のケースそのものではない）。

## 既知の限界（GPTからの指摘を反映）

- 同一試合がホーム側・アウェイ側の2レコードとして記録されるため、本来は独立
  でない観測が混在している。チーム内ペア比較はチームごとに1つの差へ集約する
  ことで一定の緩和にはなるが、厳密なクラスタ標準誤差や階層モデルではない。
- 対戦相手の強さ・ホーム/アウェイ・大会差・移動距離は未調整。
- xGデータが無く、得点/失点のみを使っている。
- 対象期間は2.5か月・380試合のみで、複数シーズンの蓄積はまだない。

これらの理由により、本分析は**因果効果の推定ではなく探索的な参考値**であり、
「疲労効果がない」ではなく「**現在のデータ量・調整の粗さでは、効果量を十分な
精度で推定できず、数値補正の根拠にできない**」という結論にとどめる。
