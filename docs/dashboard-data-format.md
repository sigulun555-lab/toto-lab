# 予想画面へのデータの渡し方（GPT・Claude共通）

画面（アーティファクト）は、データだけ差し替えれば更新される作りです。
予想の数字を、次の形で渡してください。

## 1. 基本ルール
- **締切前に保存（計算）された予想だけ**を使います。締切後の値は使いません。
- 確率は **%（0〜100）** で書きます。小数1〜2桁で十分です。
- 試合番号は、通常totoは公式の番号（1〜13）、totoGOAL3は公式の番号（1〜3）で書きます。
- モデル名は、次の表記に合わせてください（画面の表示に使います）。

| 用途 | モデル名 |
|---|---|
| Claude（v1） | `Claude v1` |
| Claude（v2・市場ブレンド） | `Claude v2` |
| GPT（v1） | `GPT v1` |
| GPT（v2・市場ブレンド） | `GPT v2` |
| Muse（v2） | `Muse v2` |
| 市場（公式投票率） | `市場（締切前）` |

## 2. 通常toto（13試合）
1行 = 1試合・1モデル。次の項目を入れます。

| 項目 | 例 | 説明 |
|---|---|---|
| round | 1673 | 回の番号 |
| match_no | 1 | 試合番号（1〜13） |
| home | 町田 | ホームのチーム名（短い名前） |
| away | 長崎 | アウェイのチーム名（短い名前） |
| model | Claude v1 | モデル名（上の表） |
| home_pct | 68.5 | ホーム勝ちの確率（%） |
| draw_pct | 15.6 | 引き分けの確率（%） |
| away_pct | 15.9 | アウェイ勝ちの確率（%） |

## 3. totoGOAL3（3試合・6チーム）
1行 = 1チーム・1モデル。次の項目を入れます。

| 項目 | 例 | 説明 |
|---|---|---|
| round | 1673 | 回の番号 |
| match_no | 1 | 試合番号（1〜3） |
| team | 町田 | チーム名（短い名前） |
| side | home | `home` か `away` |
| opponent | 長崎 | 相手チーム名 |
| integrated | 3点以上 | 統合（後述）。割れの場合は `割れ` |
| model | Claude v1 | モデル名（上の表） |
| p0 | 11.9 | 0点の確率（%） |
| p1 | 24.1 | 1点の確率（%） |
| p2 | 25.7 | 2点の確率（%） |
| p3plus | 38.2 | 3点以上の確率（%） |

**統合**：Museと市場が同じ得点区分なら、その区分（例：`3点以上`）。違えば `割れ`。

## 4. 書き込み方（データベースへ）
- 通常totoは、コレクション名 **`pred_t13`**、totoGOAL3は **`pred_g3`** に、1行を1つのドキュメントとして書きます。
- ドキュメントのIDは、次の形にします。
  - 通常toto：`<回>-<試合番号2桁>-<モデルの短い記号>`（例：`1673-01-c1`）
  - totoGOAL3：`<回>-<試合番号2桁>-<home/away>-<モデルの短い記号>`（例：`1673-01-h-c1`）
- モデルの短い記号：Claude v1 = `c1`、Claude v2 = `c2`、GPT v1 = `g1`、GPT v2 = `g2`、Muse v2 = `m2`、市場 = `mk`。
- 1回の書き込みは最大50件です。通常toto 78件、totoGOAL3 24件は、2〜3回に分けて書きます。
- 同じIDを書き直すと、そのドキュメントは上書きされます（再計算の反映に使えます）。

## 5. 締切前かどうかの確認
- 通常totoは、締切前に保存された値だけを書きます。
- 投票率（市場）は、締切前の時刻のものを使います。時刻を、回の情報欄に書いてください。

## 6. 渡し方
- GitHubのこの回のフォルダ（`data/dashboard/round_XXXX/`）に、上の形式のCSVも置いてください。
- 数字の確認は、この形式の表で行います。
