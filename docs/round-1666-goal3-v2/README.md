## ブレンド方式

GOAL3は1X2と違い、モデルの出力自体がすでに0/1/2/3+の4ブラケット確率なので、
期待得点レベルでのDixon-Coles変換は不要。確率ベクトルをそのまま重み付き平均する。

```
p_v2[k] = MARKET_WEIGHT * market[k] + (1 - MARKET_WEIGHT) * v1[k]   (k = 0,1,2,3+)
```

`MARKET_WEIGHT = 0.7` は、第1665回の1X2市場ブレンド（`scripts/claude_v2_logic.js`の
`MARKET_WEIGHT`）からの暫定流用。**GOAL3用に独立検証した値ではない。**

## 第1666回での結果（試算）

`round_1666_v2_trial.json` に全6サイド分を記録。6サイド全てでv1とv2の予想ブラケット
（argmax）は一致した（市場単独では2サイドでv1と異なるブラケットが最有力だったが、
30%のモデル重みで押し戻された）。
