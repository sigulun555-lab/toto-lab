## bootstrap の設定（訂正）
- スクリプトの既定値は **2,000回、seed 1** です（日付ブロック、日付の復元抽出）。
- 以前の README で「スクリプトは10,000回」と書いたのは誤りでした。10,000回の値は、同じ手順をインラインで実行した結果です。
- 10,000回にする場合は、`bootstrap(..., reps=10000, ...)` に変更して実行してください。
- Brier の区間は、スクリプトには含まれず、同じ手順のインライン計算（10,000回、seed 1）です。
